# AGF走行経路の指定ガイド

> 目的：利用者が図面に線と番号を記入するだけで、開発側が推測せずに「通路・方向・停止・旋回・荷役」をノード／エッジへ変換できるようにする。本ガイドは入力方法であり、実走行経路を確定するものではない。元図・現場画像・ファイル名・実座標は公開リポジトリに保存しない。

## 1. おすすめの提出物

**(A) 共通の設備位置図1枚 + (B) タスク別経路図 + (C) 補足表1枚** が最も取り違えにくい。

1. **設備位置図：** 全体が見える図面上に設備名・エリア境界・荷役点・HP・充電器・シャッター・倉庫ロケーションを記入。既に確認済みの設備名・位置は再質問せず引き継ぐ。
2. **経路図：** 上記と同じ方位・拡大率で1枚に1種類の経路を上書きする。01、02、03、04、05、充電移動をそれぞれ分離する。図面が見づらければ全体図と拡大図をセットにする。
3. **補足表：** 線の順番、通行方向、荷役／停止／旋回の区別、空走／積載、確定／仮、シャッター許可条件、未確定項目を記録する。

スマートフォン画像への手書き、ペイント、PowerPointの図形・矢印などの形式でよい。初回は距離や細かな寸法を測らなくてよい。**道筋の線と曲がる点・止まる点・通る方向**が重要。

## 2. 図面に使う記号

| 記号例 | 意味 |
| --- | --- |
| \`S01\` / \`P01\` | 通路始点・経由点（点に番号） |
| \`● H01\` | 荷役停止点（荷受け／荷下ろしは文字で明記） |
| \`□ SH01\` | シャッター。手前の停止点は別の点にする |
| \`↻ T01\` | 旋回点。進入・退出時の向きも必要なら記入 |
| \`→\` | 許可方向。逆向きも走れる場合は\`↔\` |
| \`×\` | AGF通行不可 |
| 実線 | 確認済みの経路 |
| 破線 | 仮経路、または未確定箇所（「仮」を併記） |

記号自体は変更してよい。ただし**曲がるだけの点、AGFが一時停止する点、実際に荷役する点**は必ず区別する。

## 3. 指定する順序

### STEP 1：設備と荷役点

8系列の各01荷受け点、包装機の01投入点／02回収点、整列機5点／マガジン5点、仮置き場3点、倉庫個別置場、HP・充電器2組、シャッターを図示する。包装機の西側・東側の点は一つに統合しない。

### STEP 2：共通通路

設備とは別に、通路中心線やAGFが進む線を上書きする。交差点・曲がり角・分岐を\`P01\`, \`P02\`…と採番。各区間に\`→\`または\`↔\`を付ける。エリア入退場の確定ルールと通行不可のシャッターを区別する。

### STEP 3：停止・旋回

シャッターごとに「待機する点」と「通過する点」を示す。旋回するなら\`T01\`を置き、車体の向きが重要なら進入／旋回後の矢印を記す。現時点で未確定の旋回点は「仮」と明記する。設備への停止姿勢が不明な場合も「未確定」でよい。

### STEP 4：タスク別ルート

**荷受け前の空走**と**積載後の移動**を別線で描く。AGFの初期位置が未確定なら「荷受け点以降の積載ルートだけ確定」としてよい。空走起点を勝手にHPに固定しない。

- 01：各系列の荷受け点 → 包装機01投入点。
- 02：包装機02回収点 → 倉庫の個別ロケーション。
- 03：各整列機 → 各マガジン。固定1対1にせず、**共通通路を先に示し、供給元／搬送先の取付け線を別々に指定**する。すべての組合せを25枚描く必要はない。
- 04：仮置き場3点 → 包装機01投入点。
- 05：仮置き場3点 → 倉庫の各個別ロケーション。
- 充電：AGFの現在位置 → HP／充電スペース。終了後の通常搬送再開の具体経路は別扱い。

### STEP 5：確認

図面と補足表から開発側がノード／エッジ一覧を作り直して返す。利用者が「ルートの順番・方向・停止・旋回・荷役・未確定箇所」を確認した後、確定版へ昇格する。画像を見ただけで開発側が未記入の曲がり方や停止位置を創作しない。

## 4. ルート補足表の記入例（架空の説明用）

| routeId | タスク | 区間 | 点の順番 | 停止／許可 | 状態 |

| R01-A | 01 | 積載 | H01 → P01 → T01 → H02 | H01で荷受け、H02で荷下ろし | 仮 |
| R02-A | 02 | 積載 | H03 → P02 → SH01前 → P03 → W01 | SH01通行可能待ち、W01で荷下ろし | 未確定 |

\`\`\`text

図面の上＝北、左＝西。今回書き込んだものだけを新規確定候補としてください。

対象：01（系列［名称］→包装機投入点）
線の区分：［空走／積載］
順番：［荷受け点］→［P01］→［T01］→［SH01手前］→［P02］→［荷下ろし点］
区間方向：［一方通行／双方向］
シャッター：［通過前に停止／通行可能なら連続通過／未確定］
旋回点：［T01、仮か確定か］
荷役点：［荷受け点と荷下ろし点］

既に確認済みの設備・HP・エリア入退場ルールは変更しません。
\`\`\`

## 6. まず必要な画像の優先順

1. **全体図に共通通路だけを太線で記入したもの。** 交差点・シャッター・矢印と禁止通路を記す。
2. パレタイザ付近拡大図：8系列の番号、各荷受け点、包装機01／02停止点、仮置き場3点。
3. 倉庫付近拡大図：整列機5点、倉庫個別位置、HP・充電スペース、充電器本体を区別。
4. タスク01～05と充電の経路図。まず**代表の各1ルート**を確認し、共通通路を固めてから分岐点を追加する。

なお、現段階で**走行ルート全体、各シャッターの停止座標、系列8か所の正確な順番、旋回位置は未確定**。それらは描き込んでいただいた内容だけを候補として扱い、承認までは確定値にしない。
