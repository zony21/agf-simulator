# AGF搬送シミュレーター 仕様書一覧

> **文書構成：全体仕様書1冊＋個別仕様書7冊（合計8冊）。** 以前の一体型機能仕様書v0.3は、以下の独立文書に分割・再編した。仕様の実装済み／未実装は [ハーネス契約](harness-contract.md) で区別する。

| No. | 独立文書 | 主要内容 |
| --- | --- | --- |
| 00 | [全体仕様書](specs/00-overview.md) | 目的、共通設定、イベント、画面、連携、受入条件 |
| 01 | [設備仕様書](specs/01-equipment.md) | 設備台帳、バッファ、在庫、許可、状態 |
| 02 | [通常搬送01仕様書](specs/02-transport-01.md) | パレタイザ → 包装機投入側 |
| 03 | [通常搬送02仕様書](specs/03-transport-02.md) | 包装機出口 → 倉庫ロケーション |
| 04 | [通常搬送03仕様書](specs/04-transport-03.md) | 整列機 → マガジン補充 |
| 05 | [通常搬送04仕様書](specs/05-transport-04.md) | 仮置き場 → 包装機投入側 |
| 06 | [通常搬送05仕様書](specs/06-transport-05.md) | 仮置き場 → 倉庫ロケーション |
| 07 | [AGF仕様書](specs/07-agf.md) | 車両状態・選定・充電・走行・履歴 |

**数値基準：** AGF4台、充電器2台、初期100%、消費1～2%・仮定代表1.5%、40%以下で充電・80%復帰、充電速度1%=2.4分、各系列2PL、包装投入1PL／回収2PL・3.3分/PL、マガジン残3枚で要求・+10PL。7系列全稼働の10.2PL/hrは過去最大払出実績であり、平均固定周期ではない。

**公開範囲：** 元の提供ファイル名・原本、実図・実座標、顧客・現場の識別情報は記載しない。個別レイアウトや運転ログは別管理シナリオとし、公開テストは合成データのみを使用する。

仕様が確定していない項目は各仕様書に明記する。[未確定事項一覧](open-decisions.md)も参照。
