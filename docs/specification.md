# AGF搬送シミュレーター 機能仕様書 v0.3

> **対象：シミュレーション専用アプリ。実設備の制御・安全機能の代替ではない。**
>
> 本書は「設備」「通常搬送01～05」「AGF」を中心とした開発仕様。数値はシミュレーションの初期設定として明記し、確認済み条件・設定値・仮定・未確定を区別する。
>
> **公開範囲：** 提供資料の原本・名称、元図、現場画像、実座標、顧客・現場識別情報は掲載しない。個別位置・実ルートは別管理のシナリオから読み込む。開発テストでは合成データを使う。

## 1. システム概要

設備の製品搬出、AGF選定、荷受け、搬送、包装、製品入庫、空パレット補充、待機・充電を、状態遷移の整合性が検証できるイベント駆動方式で再現する。簡易2D平面図上で履歴に基づく再生・比較を行う。

| 項目 | 仕様 | 区分 |
| --- | --- | --- |
| シミュレーション方式 | 決定論的な離散イベント方式 | 開発要件 |
| 初期再生時間 | 3時間 | 初期設定 |
| AGF台数 | 4台 | 確認済み |
| AGF選定比較 | エリア優先あり／エリア優先なし | 開発要件 |
| 画面 | 簡易2D、設備・車両・タスク・履歴・比較 | 開発要件 |
| 実機接続・実機制御 | 対象外 | 開発要件 |

本書の通常搬送01～05は**シミュレーター内の便宜ID**であり、外部機器の信号番号と同一視しない。04・05は名称が「通常搬送」であっても、起動は作業者の手動指示を想定する。

## 2. 設備仕様

### 2.1 設備台帳

| 設備 | 数量 | 主な管理対象 |
| --- | ---: | --- |
| パレタイザ／搬出コンベア | 8系列 | 系列ごとの搬出イベント、2PLバッファ |
| パレットマガジン | 5台 | 空パレット残数、補充要求・投入許可 |
| ストレッチ包装機 | 1台 | 投入、包装中、ラベル、出口状態 |
| 空パレット整列機 | 5台 | 10PL準備、搬送OK、荷受け可否 |
| 製品倉庫 | 西側・東側の個別ロケーション | 格納先、容量、在庫 |
| 共通仮置き場 | 3か所 | パレット在荷、04・05の搬送元 |
| 充電器 | 2台 | 充電設備の占有 |
| HP／充電スペース | 2台分 | AGF待機・充電位置 |
| シャッター | 複数 | 個別の通行許可・停止条件 |

HPと充電スペースは兼用。充電器本体とAGF停車位置は別の設備・位置として表現する。HP2台分以外での残りAGFの待機運用は未確定であり、4台分のHPがあるものと推測しない。

### 2.2 パレタイザ

| 設定 | 値・条件 | 区分 |
| --- | --- | --- |
| 系列数 | 8系列 | 確認済み |
| 搬出バッファ | **各系列2PL** | 確認済み |
| 01要求トリガー | **PLC搬出完了信号** | 確認済み |
| 搬出頻度の基準 | **7系列全稼働時の過去最大実績10.2PL/hr** | 参考実績 |

10.2PL/hrは「常時平均」や「一定周期の搬出イベント」を意味しない。実際の搬出時刻・稼働系列があれば入力イベント列を優先する。実績がなければ、発生時刻・系列配分を**仮定のシナリオ**として明示し、実測として表示しない。バッファ満杯時の新規搬出は成立させず、保留／ブロック理由を記録する。

管理属性：系列ID、バッファ在荷パレットID、PLC搬出時刻、01要求状態、荷受け許可、異常状態。

### 2.3 パレットマガジン

| 設定 | 値・条件 |
| --- | --- |
| 台数 | **5台** |
| 03発生 | **空パレット残数が3枚になった時** |
| 補充量 | **1回10PL** |
| 初期残数・最大容量 | 未確定、シナリオ設定 |

空パレット払い出しにより残数が3枚へ到達した遷移で、03補充要求を**一度だけ**登録する。周期評価で重複発行しない。投入前に残数と投入許可を確認し、投入完了イベントで初めて残数に10PLを加える。

### 2.4 包装機

| 設定 | 値・条件 |
| --- | --- |
| 台数 | **1台** |
| 包装タクト | **3.3分/PL**（丸め表記、能力表記は18PL/hr） |
| 投入側バッファ | **1PL** |
| 回収側バッファ | **2PL** |
| 01側の荷下ろし停止点 | 投入側に1か所 |
| 02側の荷受け停止点 | 回収側に1か所 |

投入バッファ・包装処理中・回収バッファは別資源。01荷下ろし → 投入・RFID照合 → 包装開始／完了 → ラベル貼付完了 → 出口到達・搬出OK → 02要求の順で、各段階を別イベントとする。**包装完了だけでは02を発生させない。** ラベル、移送、荷役の区間別処理時間は別途設定し、未確定値を包装タクトへ無断で含めない。

### 2.5 空パレット整列機

5台それぞれに設備ID・荷受け停止点を持たせる。作業者が10PLを準備し搬送OKを指示した設備のみ、03の供給元候補とする。整列機とマガジンの対応は固定1対1ではなく、搬送OKの整列機から補充先を選択できる。

### 2.6 製品倉庫・仮置き場・シャッター

- 02・05は倉庫エリアの代表点だけでなく、**個別の指定ロケーション**まで搬送して入庫を記録する。
- 仮置き場は3か所を04・05共通で利用する。各仮置き場に個別の荷役停止点を持つ。
- 走行は基本双方向。エリア間の進入・退出制約とシャッターごとの停止点・通行許可は、外部レイアウト設定で管理する。
- 未確定の走行線・旋回点・停止点は仮表示とし、実距離・確定ETAの根拠としない。

## 3. 通常搬送01：パレタイザ → 包装機

| 項目 | 仕様 |
| --- | --- |
| 搬送元 | 搬出完了した系列の荷受け点 |
| 搬送先 | 包装機投入側 |
| 発生条件 | PLC搬出完了信号 |
| 完了条件 | 投入許可を確認した包装機への荷下ろし完了 |

**処理：** 製品搬出 → RFID・製品情報の処理 → 01要求 → AGF選定／割当 → 系列へ空走 → 荷受け許可確認 → 荷受け → 包装機へ実搬送 → 投入許可確認 → 荷下ろし → 01完了・包装工程へ引渡し。

要求発生時刻、荷受け可否、荷下ろし可否は別状態。RFID異常などの例外搬送は通常の01完了・02生成と混同しない。

## 4. 通常搬送02：包装機 → 製品倉庫

| 項目 | 仕様 |
| --- | --- |
| 搬送元 | 包装機回収側 |
| 搬送先 | 指定された倉庫ロケーション |
| 発生条件 | **対象PLの包装・ラベル貼付完了、出口到達・搬出OKの成立後** |
| 完了条件 | 指定位置への荷下ろし・入庫実績登録 |

**処理：** 01完了の対象パレットを包装機が処理 → 包装完了 → ラベル貼付完了 → 出口搬出OK → 02要求 → AGF選定／割当 → 包装機回収側で荷受け → 倉庫指定位置へ搬送 → 荷下ろし・在庫更新。

01・包装工程・02は**同一パレットID**で追跡する。01完了や包装完了から一定時間を足すだけの02生成は禁止。

## 5. 通常搬送03：整列機 → マガジン

| 項目 | 仕様 |
| --- | --- |
| 搬送元 | 搬送OKの空パレット整列機 |
| 搬送先 | 残数が閾値に達した対象マガジン |
| 発生条件 | **対象マガジン残数が3枚になった時** |
| 搬送量 | **10PL** |
| 完了条件 | 残数・投入許可確認後の10PL投入実績 |

**処理：** 空パレ消費 → 残3枚到達 → 03要求 → 搬送OK整列機選択 → AGF選定／割当 → 整列機へ空走 → 荷受け許可 → 10PL荷受け → マガジンへ実搬送 → 投入前残数確認・投入許可 → 荷下ろし → 補充実績・残数更新。

供給元が搬送OKでない場合は要求を待機させる。マガジン初期残数・最大容量は未確定であり、勝手に固定しない。

## 6. 通常搬送04：仮置き場 → 包装機

| 項目 | 仕様 |
| --- | --- |
| 搬送元 | 共通仮置き場3か所の指定位置 |
| 搬送先 | 包装機投入側 |
| 発生条件 | **作業者の手動搬送指示** |
| 完了条件 | 包装機への荷下ろし完了 |

**処理：** 対象パレット・仮置き位置指定 → 04要求 → AGF選定／割当 → 仮置き場へ移動・荷受け → 包装機へ搬送 → 投入許可 → 荷下ろし → 包装工程へ引渡し。

再投入時のデータ修正や異常復旧条件は未確定。通常搬送01のPLC搬出完了イベントを新たに捏造しない。

## 7. 通常搬送05：仮置き場 → 製品倉庫

| 項目 | 仕様 |
| --- | --- |
| 搬送元 | 共通仮置き場3か所の指定位置 |
| 搬送先 | 指定された倉庫ロケーション |
| 発生条件 | **作業者の手動搬送指示** |
| 完了条件 | 指定位置への荷下ろし・入庫実績登録 |

**処理：** 対象パレット・仮置き位置・入庫先指定 → 05要求 → AGF選定／割当 → 仮置き場へ移動・荷受け → 倉庫へ搬送 → 荷下ろし・在庫更新。

入庫対象の包装状態・手動検査・復旧許可など、具体的な受入条件は未確定。未包装のまま自動入庫可と見なさない。

## 8. AGF仕様

### 8.1 基準シナリオ設定

| 設定 | 値 | 区分 |
| --- | --- | --- |
| AGF台数 | **4台** | 確認済み |
| 充電器台数 | **2台** | 確認済み |
| Battery初期値 | **100%** | シミュレーション初期設定 |
| 1搬送消費 | **1～2%** | ユーザー確認範囲 |
| 代表消費 | **1.5%** | **仮定・要確定** |
| 充電開始 | **40%以下** | 今回のシミュレーション設定 |
| 通常搬送復帰 | **80%** | 今回のシミュレーション設定 |
| 充電速度 | **1%=2.4分** | 今回のシミュレーション設定 |

閾値・充電速度は変更可能なシナリオ入力とする。代表値1.5%は実測確定値として固定しない。空走・走行距離・タスク種別ごとの差分は未確定。

### 8.2 状態

待機／荷受け地点への空走／荷受け中／実搬送／荷下ろし中／充電場所へ移動／充電待ち／充電中／異常。車両1台に複数タスクを同時割当しない。

### 8.3 車両選定

- 選定可能：待機中でタスク実行可能、異常・通信異常・有人モード・充電中・充電待ち・別タスク中でない車両。
- **エリア優先あり**：最初の荷受けエリアと現在エリアの一致を優先し、同条件では低残量順。
- **エリア優先なし**：エリアによる並べ替えをせず低残量順。
- 同率はAGF ID順で再現可能に決定する。
- 選定条件からエリアを外しても、実際の移動時間・経路から現在位置を除外しない。

比較時は外生生産入力、初期位置・初期残量、設備条件、その他の設定を共通にし、選定方式だけ変更する。

### 8.4 充電

残量40%以下で充電要求 → 現タスクの扱いを確認 → 充電位置へ移動 → 空き充電器なら充電開始、満杯なら待機 → 80%到達で充電終了・通常搬送復帰。**実行中タスクを中断するか、完了後に充電へ移るかは未確定**。充電位置への移動完了より前に充電を開始しない。

## 9. 共通エンジン・画面・データ

### 9.1 イベントと制約

- イベント時刻は非負整数ミリ秒、同時刻はsequenceで順序を一意化する。
- 「要求・割当・荷受け許可・荷受け・移動・荷下ろし・設備工程・完了」を独立したイベントとして記録する。
- パレットID／タスクID／AGF ID／設備ID／ロケーションIDを関連付ける。
- 二重割当、設備容量超過、工程順序逆転、補充要求重複、充電器の二重占有を検出する。
- 容量不足・許可待ち・設備異常は状態と理由を履歴に残し、無条件で処理を進めない。
- 同じ入力シナリオとシードで、同じイベント履歴と集計値を生成する。

### 9.2 2D表示・操作

- 中央に簡略平面図、車両は色と番号で区別したアイコン、設備は台帳IDで表示。
- 再生／一時停止／コマ送り／速度変更／任意時刻へシーク。
- 現在タスク、残量、車両状態、設備占有、バッファ数、待ち列、充電器使用状態を表示。
- イベント履歴、AGFタイムライン、CSV出力を提供する。
- 選定方式の比較には、同一入力での入庫件数、要求／完了件数、待ち時間、滞留、空走、充電待ち、稼働率を表示する。
- **仮設定／確定設定／実測入力**の区分を画面・出力で明示。アニメーションは計算済みのイベント履歴から再生し、独自の時計で工程完了時刻を変更しない。

## 10. 受入条件

- 01はPLC搬出完了前に発生しない。
- 02は対象PLの包装・ラベル貼付・出口搬出OKより前に発生しない。
- 03要求は残数3枚到達時に一度だけ発行し、実際の投入完了前に+10PLしない。
- 系列2PL／包装機投入1PL・回収2PL／充電器2台の制約を超えない。
- 同一パレットの重複搬送、1台AGFへの二重割当、未許可の荷役を拒否する。
- 04・05は指定された仮置き場のパレットに対する手動要求を前提とする。
- 任意時刻でのUI状態は同時刻のイベント履歴から再現できる。
- 未確定経路から確定ETAを出さない。
- 同一入力を両選定方式に供給し、方式だけを変更して比較できる。
