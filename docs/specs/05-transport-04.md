# 05. 通常搬送04 仕様書 v1.0

**独立仕様書**／関連：[全体](00-overview.md)・[設備](01-equipment.md)・[02搬送](03-transport-02.md)・[05搬送](06-transport-05.md)・[AGF](07-agf.md)

## 1. 目的・対象

仮置き場の製品パレットを包装機投入側へ再搬送する。04はシミュレーター内の便宜ID。現在確認できているのは**搬送元・搬送先と、作業者の手動要求を用いる案**であり、実運用の例外復旧条件は未確定とする。

| 項目 | 仕様・扱い |
| --- | --- |
| タスクID | 04 |
| 搬送元 | 3か所の共通仮置き場の指定位置 |
| 搬送先 | 包装機投入側（01と共用する投入位置） |
| 発生契機 | 作業者が対象パレットを指定した手動要求（詳細運用は要確認） |
| 完了条件 | 包装機受入許可後の荷下ろし完了 |
| 次工程 | 対象パレットの包装・ラベル・出口OK後に02へ接続 |

## 2. 入力・前提

`palletId`, `temporaryLocationId`, `requestedBy`, `requestTime`, `reentryPermission`, `wrapperInputAvailable`, `agfId`。仮置き場3位置は共通供給元であるが、各位置の荷役停止点は別に管理する。パレットの実在、既存予約の有無、包装機へ戻す許可を判定する。

## 3. 処理フロー

1. 作業者が仮置き場、対象パレット、包装機への再投入を指定する。
2. 対象が在荷し未予約であることと、必要な再投入許可を確認する。
3. 04要求を生成し、実行可能なAGFを割り当てる。
4. AGFは現在位置から指定仮置き場の個別停止点へ空走する。
5. 荷受け許可後、当該パレットを荷受けし、仮置き在荷から除く。
6. 包装機投入側まで実搬送し、投入バッファ1PLの受入許可を待つ。
7. 荷下ろし完了を記録し、包装工程へ同じパレットIDを引き渡す。
8. 包装・ラベル・出口搬出OKが成立すれば02要求の対象とする。

## 4. 状態と禁止事項

`REQUESTED → WAIT_REENTRY_PERMISSION → ASSIGNED → MOVING_EMPTY → PICKING → MOVING_LOADED → WAIT_WRAPPER_INPUT → DROPPING → COMPLETED`。再投入許可なし、パレット不存在、別タスク予約済み、包装機満杯は保留または拒否。04の処理で新しいPLC搬出完了や別の製品パレットIDを捏造しない。

## 5. 設備・他タスクとの関係

- 仮置き場は05とも共通。**同じ在荷を04と05に二重引当しない**。
- 包装投入側は01とも共通で、投入1PLの容量を守る。
- 04完了は02発生を直接意味しない。包装後のラベル・出口OKが必要。
- RFID照合不良など、仮置きに至った異常の解消条件は別途定義し、未確認のまま正常工程に流さない。

## 6. 出力・受入・未確定

記録：`palletId`, `temporaryLocationId`, `manualRequestAt`, `permissionStatus`, `agfId`, `pickedAt`, `dropoffAt`, `completedAt`, `waitReason`。

受入条件：対象在荷と手動要求がない04は作成しない。荷受け前に仮置き在庫を消さない。投入許可前に包装機へ置かない。04完了後の02生成は包装後の条件を守る。

**未確定：** 手動指示・異常復旧の正式な操作手順、製品情報の再照合、搬送可否の承認者／許可条件、走行・荷役時間。
