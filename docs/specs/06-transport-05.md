# 06. 通常搬送05 仕様書 v1.0

**独立仕様書**／関連：[全体](00-overview.md)・[設備](01-equipment.md)・[02搬送](03-transport-02.md)・[04搬送](05-transport-04.md)・[AGF](07-agf.md)

## 1. 目的・対象

共通仮置き場から製品倉庫の指定ロケーションへ製品パレットを搬送する。05はシミュレーター内の便宜ID。手動要求の詳細・製品状態に応じた直接入庫許可条件は**未確定**である。

| 項目 | 仕様・扱い |
| --- | --- |
| タスクID | 05 |
| 搬送元 | 3か所の共通仮置き場の指定位置 |
| 搬送先 | 製品倉庫の個別指定ロケーション |
| 発生契機 | 対象パレットと入庫先を指定した作業者の手動要求（詳細運用は要確認） |
| 完了条件 | 個別位置への荷下ろし完了・入庫実績 |

## 2. 入力・前提

`palletId`, `temporaryLocationId`, `destinationLocationId`, `productStatus`, `storagePermission`, `manualRequestAt`, `agfId`。搬送前に対象PLの在荷・未予約、製品状態、入庫先の空きと受入許可を確認する。**未包装のパレットを自動的に入庫可とは見なさない**。

## 3. 処理フロー

1. 作業者が搬送元の仮置き位置、対象パレット、倉庫の個別搬送先を指定する。
2. 対象パレットの在荷と04/05重複予約の有無を確認する。
3. 製品状態・入庫許可・倉庫ロケーションの受入可能性を確認する。
4. 05要求を作成し、実行可能なAGFを割り当てる。
5. AGFが仮置き場へ空走し、荷受け許可後に対象パレットを荷受けする。
6. 倉庫の指定ロケーションへ実搬送する。
7. 荷下ろし許可確認後に指定位置へ荷下ろしする。
8. 05完了実績を記録し、当該ロケーションの在庫を更新する。

## 4. 状態と禁止事項

`REQUESTED → WAIT_STORAGE_PERMISSION → ASSIGNED → MOVING_EMPTY → PICKING → MOVING_LOADED → WAIT_LOCATION_AVAILABLE → DROPPING → COMPLETED`。許可未成立、位置未指定、庫内満杯、走行不可は理由付き保留／拒否。パレットを搬送していないのに仮置き在荷を消さない。倉庫到着だけで入庫数を増やさない。

## 5. 他タスクとの関係

- 04と05は同じ3か所の仮置き場を共有し、**同一パレットに同時引当しない**。
- 02と05は倉庫ロケーションを共有する。入庫先容量・予約を競合管理する。
- 05による直接入庫は包装工程を経る02とは別経路である。05から包装完了イベントや02要求を自動生成しない。
- 例外品の取扱いと有人搬送に切替える条件は別途確定する。

## 6. 出力・受入・未確定

記録：`palletId`, `temporaryLocationId`, `destinationLocationId`, `productStatus`, `storagePermission`, `agfId`, `pickedAt`, `storedAt`, `waitReason`。

受入条件：手動要求と対象PLの在荷がない05は拒否する。ロケーション未指定・許可未成立のまま入庫しない。02・05の在庫を二重加算しない。

**未確定：** 包装状態別の入庫許可、検査／復旧の手順、個別ロケーション容量・座標、走行・荷役時間。
