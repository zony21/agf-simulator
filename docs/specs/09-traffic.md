# 09. AGF通行・車線仕様書 v0.1（段階確認）

**独立仕様書**／関連：[全体マップ](08-map.md)・[設備](01-equipment.md)・[AGF](07-agf.md)・[経路指定ガイド](../route-annotation-guide.md)

> この文書は走行可否と車線の確認台帳。図面の矢印をそのまま「一方通行」「2車線」とは解釈しない。実図、実座標、現場識別情報、提供資料の名称はこの公開リポジトリに保存しない。

## 1. 確定の順序

1. **第1段階：通行できる場所を確定。** AGFが通過できる通路区間、設備への取付け通路、通行禁止区画、必要な通行許可を区間ごとに確定する。この段階では往来可能性、車線数、すれ違い可否、停止・旋回の安全性を確定しない。
2. **第2段階：第1段階で通行可能とされた区間ごとに、方向・車線数・すれ違いを確定。** 「双方向通行」と「2車線」を別属性とする。双方向1車線なら同時すれ違いの可否と退避／区間占有制御を別に確認する。
3. **第3段階（後続）：停止点・旋回点・優先順位・区間占有・距離・速度・時間を確認。** 前段階の未確定を推測で補完しない。

## 2. 判定単位と属性

**通路（Segment）**はシャッター、交差点、分岐、設備取付け口など、通行条件が変わる地点で分割する。設備・保管ロケーション自体と、そこへアクセスする走行通路を混同しない。

| 項目 | 値の例 | 確認段階 |
| --- | --- | --- |
| `segmentId` | 公開用の抽象ID | 初期 |
| `access` | `allowed` / `forbidden` / `unresolved` | 第1段階 |
| `accessScope` | 空走／積載／充電移動等、条件に差がある場合 | 第1段階 |
| `permission` | シャッター通行OKなど必要条件 | 第1段階 |
| `direction` | 双方向／指定方向のみ／未確定 | 第2段階 |
| `laneCount` | 1／2／その他／未確定 | 第2段階 |
| `simultaneousPassing` | 可／不可／制御条件付き／未確定 | 第2段階 |
| `turnStopStatus` | 確定／仮／未確定 | 第3段階 |
| `evidenceStatus` | 利用者確認／図示候補／未確定 | 全段階 |

通路方向、車線数、同時すれ違いは独立して記録する。矢印の本数は車線数を意味しない。ピンク等で表示した保管マスは**製品パレットロケーション**であり、マス全体が走行可能な道路とは扱わない。

## 3. 第1段階：通行できる場所

### 3.1 既に確認されている運用制約

| 論理区分 | AGF通行 | 補足 |
| --- | --- | --- |
| 製品倉庫の通常出入口 | 東側出入口を使用 | 出入ルール確認済み。車線数は未確定 |
| 製品倉庫の西側出入口 | **使用しない** | AGFの経路候補から除外 |
| パレタイザエリアの入口 | 西側から進入 | 運用ルール確認済み |
| パレタイザエリアの出口 | 東側から退出 | 運用ルール確認済み |
| 空パレット保管マス | AGFの03直接荷受け対象外 | 整列機と保管場所を区別 |
| 個別製品保管マス | 個別ロケーションを搬送先として扱う | マス内部を走行路として自動登録しない |

上表は全走行線の確定を意味しない。シャッターの開閉・通行可能信号の前提も、単なる走行線と区別する。

### 3.2 製品倉庫図から抽出した確認候補

図に描かれた線や代表入庫経路を**候補として**抽出した。各行の通行可否は利用者の回答で確定し、未回答のものは`unresolved`のままとする。

| 候補ID | 通行区間 | 第1段階の状態 |
| --- | --- | --- |
| WH-E-V | 東側の縦方向の通路（倉庫出入口から内側） | 図示候補・全区間の可否未確定 |
| WH-W-V | 西側の縦方向の通路 | 図示候補・全区間の可否未確定 |
| WH-X-U | 上段の防火シャッター経由の東西接続通路 | 代表経路に図示。全方向／全用途は未確定 |
| WH-X-L | 下段の防火シャッター経由の東西接続通路 | 図示候補・通行可否未確定 |
| WH-W-A | 西側の上部保管列へのアクセス通路 | 図示候補・通行可否未確定 |
| WH-W-B | 西側の中央保管列へのアクセス通路 | 代表の荷下ろし経路に図示。その他の列は未確定 |
| WH-W-C | 西側の下部保管列へのアクセス通路 | 図示候補・通行可否未確定 |
| WH-E-A | 東側の上部保管列へのアクセス通路 | 図示候補・通行可否未確定 |
| WH-E-B | 東側の下部保管列へのアクセス通路 | 図示候補・通行可否未確定 |
| WH-SERVICE | 整列機・HP／充電位置へ到達する接続通路 | 取付け経路未確定 |

西側の上・中央・下および東側の上・下は**確認対象を区別するための仮ID**。実際の道路数、位置、保管列数、合流位置を表す確定IDではない。設備・倉庫の個別停止点や連絡通路の詳細は、画像上で分割点を指定して改訂する。

**代表入庫経路の図示内容：** 東側入口 → 東側内部の縦方向 → 上段の東西接続（防火シャッター）→ 西側縦方向 → 西側の横方向 → 個別ロケーションの荷下ろし点。この一例はすべての保管列で同経路を使う保証ではない。

## 4. 第1段階の確定方法

各候補区間について `通行できる`／`通行できない`／`一部のみ通行できる`／`未確定` を選ぶ。一部の場合は「図上どこからどこまでか」を示して区間を分割する。アクセスにシャッター通行許可など条件があれば追記する。回答で確定するまでは候補区間をルーティングの通行可能エッジに採用しない。

## 5. 第2段階：方向・車線・往来条件（第1段階完了後に確認）

| segmentId | 方向 | 車線数 | 同時すれ違い | 必要な運用制御 | 状態 |
| --- | --- | --- | --- | --- | --- |
| 第1段階で通行可となった区間 | 未確定 | 未確定 | 未確定 | 未確定 | 未着手 |

方向は「双方向」「片方向（具体的な進行向きを記録）」とする。車線数は「1」「2」「その他」で記録し、往来可能かどうかと**同時にすれ違えるかどうか**は別に確認する。例えば「双方向・1車線」は交互通行の可能性があり、同時すれ違い可能という意味ではない。「青い線」「オレンジの線」を自動的に別の車線とみなさない。

## 6. 受入条件・更新規則

- 第1段階で`forbidden`の区間は経路探索対象にしない。
- `unresolved`は通行可能扱いにせず、確認待ちを表示する。
- 片方向を確定するまでは、図示の矢印だけで逆方向の可否を推測しない。
- 双方向でも車線数・同時すれ違いを確定するまでは、AGF2台の同時通過可能としない。
- 実ルート、停止点、旋回位置、衝突回避が未確定の段階では実機相当の安全性や確定ETAを主張しない。
- 変更ごとに改訂番号と対象区間を記録し、ユーザー確認済み事項を繰り返し未確定扱いに戻さない。
