# 製品倉庫の概念構造・表示契約（2026-10-28 改訂）

本資料は確認された相対配置と通常／迂回の論理運用を扱う。実CAD座標、寸法、停止点、車体離隔、具体的なルート接続は未確認。仕様の確定とコードへの実装は区別する。外周シャッターは [08a](specs/08a-pz-wh-gate-position.md)、通行条件は [09](specs/09-traffic.md) を参照。

## 2. 西側通路とWH西シャッターの位置

- 倉庫中央の防火シャッターのある壁は東西区画を分ける内部壁。防火SHは2か所。自由横断は不可。
- 中央壁と製品置場の間にある既存主通路は西2本・東2本の計4本を維持。保管ブロック側が北→南、中央壁側が南→北を初期交通方向とする。各行は双方向1車線で横並び通過は不可。
- **WB1の西側に2車線通路が存在する。** 中央壁沿いの西側主通路2本とは別の位置関係であり、同じ道路を重複登録しない。
- **WB1とWB2の間に迂回用の1車線通路が存在する。** WB1西側2車線通路とは別に管理する。
- **WH西SHは北側外壁にある。西側外壁ではない。** 西側製品置場よりさらに西側奥にあり、中央防火SH壁には隣接しない。
- 東から西へのおおよその順序は「中央防火SH壁 → 西側主通路 → 西側製品置場 → WB1西側の2車線通路・WH西SHのある西奥の領域」。これは実座標や各区間の接続を保証しない。
- WH東SHも北側外壁に存在し、WH西SH・東SHは共に倉庫と外通路の境界設備。中央防火SHとは別物。
- **WH外周SHはAGF2台が並んで通過できる。シャッター通過だけを理由に不要な旋回を追加しない。** 開口前後の旋回は別判定。個別レーン方向・対向同時通過・予約信号・停止点は未確認。

## 3. WB1・WB2間の可変置場【確定】

| モード | 2行×13列（26平面マス）の使い方 |
| --- | --- |
| **通常** | 製品パレット置場として使用可能。迂回用通路としては使用不可 |
| **迂回** | パレット配置・新規予約禁止。**1車線のAGF通路**として使用 |

段数と正式なロケーションIDは未確認であり、26平面マスを52PLと断定しない。可変領域は既存固定802PLとは別管理する。迂回モードで通路として使用する前に**在荷なし・搬入予約なし・使用中の搬送タスクなし**を確認する。残存パレットを削除・瞬間移動させて通路化してはならない。切替手順、接続地点、迂回解除条件は要確認。

## 4. 通常／迂回ルート

| モード | 使用する倉庫外周SH | 倉庫→パレタイズ | パレタイズ→倉庫 |
| --- | --- | --- | --- |
| 通常 | **WH東SH** | WH東SH → 外通路 → PZ入口SH | PZ出口SH → 外通路 → WH東SH |
| 迂回 | **WH西SH** | WH西SH → 外通路 → PZ出口SH | PZ入口SH → 外通路 → WH西SH |

迂回時はPZ入口SHとPZ出口SHの**運用上の入口／出口が逆転**する。開口自体の位置・IDを変更しない。外通路・倉庫の実接続、交通方向、モード切替操作は要確認。迂回シミュレーションは実装・テスト対象であり、資料更新だけで実装済みとはしない。

## 5. EB2南側：整列機移設と通常待機

| 対象 | 新仕様 |
| --- | --- |
| 旧HP1・HP2 | **待機場所を廃止**。旧HPエリアを整列機の配置場所にする |
| 空パレット整列機AL1～AL5 | **縦一列に移設**。AGFは各整列機の**左側（西側）**から空パレット取得 |
| 充電場所1・2／充電器2台 | **位置・台数とも変更しない**。充電場所と充電器本体は別管理 |
| 空パレット置場 | AGF進入禁止の有人供給元。変更後の詳細位置は未確認 |
| 柱前通常待機・東 | EB1とEB2の間の空き領域の西寄り。既存位置維持 |
| 柱前通常待機・西 | WB2とWB3の間の空き領域の東寄り。既存位置維持 |

搬送03は5台それぞれの個別荷受け点を持ち、既存の東側主通路群からアクセスする。東側の主通路を3本に増やさない。整列機前通路、左側荷役姿勢、停止・旋回・退出、充電動線との競合は要確認。

**通常待機場所は柱前東・西の2か所を優先**。AGFは4台であり、2か所満車時の帰還・待機方法は未確定。充電場所の通常待機代用を勝手に現場確定運用としない。旧AGF3→HP1、AGF4→HP2という初期配置は廃止エリアに当たるため無効で、改訂後4台の初期配置は未確定。

**先方打診・未確定：** PZ入口と出口の間の**建屋外側、外通路の庇下**を新しい待機場所として使用できないか。使用台数、停止位置、進入経路、シャッター・一般通行との干渉、運用承認は未確認。確定前に通常待機場所として扱わない。

## 6. 設計・実装に残る確認

1. WH西SHの北壁上の正確な開口位置、前後の2台並列通過用通路接続、進行方向・排他信号。
2. WB1西側2車線通路とWB1・WB2間1車線通路の分岐・接続位置、旋回点、車体幅と通過離隔。
3. 可変置場の段数・正式ロケID、在荷ゼロと予約解除の確認、迂回切替インターロック。
4. 整列機AL1～AL5の個別停止・左側荷受け、荷役中の後続通過と充電動線との干渉。
5. 旧HP廃止後のAGF4台初期配置、柱前2か所が満車時の帰還先と待機方法。
6. 外通路庇下の待機場所追加の採否。
