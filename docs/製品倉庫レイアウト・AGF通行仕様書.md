## 1. レイアウトの基本構造

製品倉庫は、中央の壁によって西側と東側に分かれる。

中央の壁はAGFが自由に横断できる構造ではない。東西の往来は、壁に設置された2か所の防火シャッターを通る場合に限る。

壁に平行な主通路は、次の構成とする。

| 区域     | 壁に平行な主通路 |
| -------- | ---------------: |
| 西側     |              2本 |
| 東側     |              2本 |
| **合計** |          **4本** |

この4本の主通路から、各製品置き場ブロックの行レーンへ接続する。

> **重要：主通路が各側2本ある構成を変更しないこと。**
>
> ブロック内に複数の行レーンが存在することを理由に、壁沿いの主通路を増やしてはならない。

## 3. 主通路とブロック内レーンの違い

本システムでは、次の2種類を別々の走行経路として管理する。

| 項目                        | 壁沿いの主通路                           | ブロック内の行レーン             |
| --------------------------- | ---------------------------------------- | -------------------------------- |
| 役割                        | 倉庫内の主要な移動                       | 各置き場ロケーションへのアクセス |
| 本数                        | 西側2本・東側2本                         | ブロックの行数に応じて存在       |
| 進行方向                    | 主通路ごとの方向・同時通過条件は別途確認 | 双方向                           |
| 1本の行レーンでの横並び通行 | 該当しない。主通路の通行条件として別管理 | 不可                             |
| 接続先                      | 防火シャッター、ブロック内の行レーン等   | 各パレット置き場ロケーション     |

### 3.1. ブロック内の行レーンについて

ブロックの各行を、それぞれ双方向の1車線レーンとして扱う。

例えば、WB1は7行あるため、ブロック内に7行分の走行レーンが存在するイメージである。

1本の行レーンではAGFが双方向に走行できるが、2台が横に並んで通行することはできない。

したがって、次の解釈は禁止する。

- 「双方向通行可能」＝「横並びで2台が通行可能」
- 「ブロックに複数行ある」＝「1本の行レーンが複数車線」
- 「西側に主通路2本ある」＝「WB1の各行も2車線」

対向するAGFの待機・譲り合い・区間占有は、後続の交通制御で扱う。

隣接する別の行の同時利用条件とは分けて管理する。

## 6. AGFの経路を作成する際の原則

経路の構築順序は次のとおりとする。

1. 西側2本・東側2本の主通路を独立した通路として定義する。
2. 中央の壁を通行不可とし、防火シャッター2か所のみを東西接続候補とする。
3. WB1～WB3、EB1～EB2の各行に、独立した双方向1車線の行レーンを定義する。
4. 主通路と各行レーンの接続点を、確認済みの図面情報に基づいて登録する。
5. 各行レーンから、個別のパレット置き場ロケーションへアクセスできるようにする。
6. 東側ブロックの中央空列には、パレットロケーションを生成しない。
7. EB2南側のHP待機2か所は廃止。整列機5台は旧HPエリアに縦一列・西側荷受け、充電2か所は移動せず、既存東側主通路群からアクセス。分岐点は未確認のままとする。
8. 空パレ置き場はAGF進入禁止として扱い、整列機との間に自動で走行辺を追加しない。

通路の交差や近接を画像から推測して、自動的に接続点を作成してはならない。

## 9. 最重要ルール

**壁沿いの主通路は西2本・東2本の計4本で固定する。**

それとは別に、各ブロックの各行を双方向1車線の走行レーンとして管理する。

**行レーン内でAGF2台が横並び通行することはできない。**

この条件を、今後のレイアウト作成・経路生成・搬送シミュレーションにおける共通の前提条件とする。

**EB2南側では待機2か所・充電2か所を区別し、整列機5台を搬送03の荷受け元とする。空パレ置き場にはAGFを進入させない。**

### パレタイズエリア設備列の順序

西から東の順序は次のとおり。

`PGW8 → PM1 → PGW7 → PM2 → PGW5 → PM3 → PGW4 → HI → 包装機 → HO → PGW2 → PM4 → PGW1 → PGW3 → PM5 → PGW6`

**PZ外周の出入口・外通路・WH外周シャッターの位置関係は本資料で独自定義しない。最新の正は `docs/specs/08-map.md` / `docs/specs/09-traffic.md`。PZ入口SHは包装機HO正面付近、PZ出口SHはその東側、WHはPZに対して東へオフセットし、CAD境界を確認済み開口以外で横断しない。**
