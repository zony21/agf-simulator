## 1. レイアウトの基本構造

製品倉庫は、中央の壁によって西側と東側に分かれる。

中央の壁はAGFが自由に横断できる構造ではない。東西の往来は、壁に設置された2か所の防火シャッターを通る場合に限る。

壁に平行な主通路は、次の構成とする。

| 区域     | 壁に平行な主通路 |
| -------- | ---------------: |
| 西側     |              2本 |
| 東側     |              2本 |
| **合計** |          **4本** |

この4本の主通路から、各製品置き場ブロックの行レーンへ接続する。

> **重要：主通路が各側2本ある構成を変更しないこと。**
>
> ブロック内に複数の行レーンが存在することを理由に、壁沿いの主通路を増やしてはならない。

## 3. 主通路とブロック内レーンの違い

本システムでは、次の2種類を別々の走行経路として管理する。

| 項目                        | 壁沿いの主通路                           | ブロック内の行レーン             |
| --------------------------- | ---------------------------------------- | -------------------------------- |
| 役割                        | 倉庫内の主要な移動                       | 各置き場ロケーションへのアクセス |
| 本数                        | 西側2本・東側2本                         | ブロックの行数に応じて存在       |
| 進行方向                    | 主通路ごとの方向・同時通過条件は別途確認 | 双方向                           |
| 1本の行レーンでの横並び通行 | 該当しない。主通路の通行条件として別管理 | 不可                             |
| 接続先                      | 防火シャッター、ブロック内の行レーン等   | 各パレット置き場ロケーション     |

### 3.1. ブロック内の行レーンについて

ブロックの各行を、それぞれ双方向の1車線レーンとして扱う。

例えば、WB1は7行あるため、ブロック内に7行分の走行レーンが存在するイメージである。

1本の行レーンではAGFが双方向に走行できるが、2台が横に並んで通行することはできない。

したがって、次の解釈は禁止する。

- 「双方向通行可能」＝「横並びで2台が通行可能」
- 「ブロックに複数行ある」＝「1本の行レーンが複数車線」
- 「西側に主通路2本ある」＝「WB1の各行も2車線」

対向するAGFの待機・譲り合い・区間占有は、後続の交通制御で扱う。

隣接する別の行の同時利用条件とは分けて管理する。

## 6. AGFの経路を作成する際の原則

経路の構築順序は次のとおりとする。

1. 西側2本・東側2本の主通路を独立した通路として定義する。
2. 中央の壁を通行不可とし、防火シャッター2か所のみを東西接続候補とする。
3. WB1～WB3、EB1～EB2の各行に、独立した双方向1車線の行レーンを定義する。
4. 主通路と各行レーンの接続点を、確認済みの図面情報に基づいて登録する。
5. 各行レーンから、個別のパレット置き場ロケーションへアクセスできるようにする。
6. 東側ブロックの中央空列には、パレットロケーションを生成しない。
7. EB2南側の待機2か所・充電2か所・整列機5台を製品倉庫のロケーションとは別に登録し、EBと同じ東側主通路からアクセスする論理接続を持たせる。ただし分岐点・接続先となる主通路1／2の割当は未確認のまま扱う。
8. 空パレ置き場はAGF進入禁止として扱い、整列機との間に自動で走行辺を追加しない。

通路の交差や近接を画像から推測して、自動的に接続点を作成してはならない。

## 9. 最重要ルール

1. **既に確定した仕様は維持し、今回指摘された箇所だけ修正する。** 一箇所の変更を理由に他の設備数、通路本数、待機候補、シャッター運用、搬送条件を戻さない。

## 1. 全体の上下関係と開口の区別

図面の上＝北、下＝南、左＝西、右＝東。全体は**パレタイズエリア（北）→ 外通路 → 製品倉庫（南）**の順。2建屋は外通路を挟んでおり、壁を共有しない。

- パレタイズエリアの**北面にAGFの入口を描かない**。パレタイズの入口・出口SHはいずれも**南面**に置く。
- 製品倉庫の西SH・東SHはいずれも製品倉庫の**北面（外通路側）**。パレタイズ側のSHと別設備、別ゲートID、別の許可・停止点で扱う。
- 中央壁の「北防火SH」「南防火SH」は**製品倉庫内の西側・東側の横断設備**。建屋の出入口SHと混同しない。
- パレタイズ側の入口・出口と、製品倉庫側の入口・出口を名称だけで同じx座標に置くのではなく、下記の位置合わせ条件に従う。

### 1.1 南北位置合わせの必須条件

**同一の南北軸上に、次の順で配置する。**

```text
              北（パレタイズ建屋内）
                        │
             パレタイズ出口SH
                        │  建屋南面
                        │
                  外通路の直進部分
                        │
               製品倉庫東SH
                        │  倉庫北面
                        │
             東側主通路2本の通路群
                        │
             南（製品倉庫内）
```

「真上／一直線」は**パレタイズ出口SHの開口中心、製品倉庫東SHの開口中心、東側主通路2本の通路群の中心を南北方向に合わせる**という描画条件。主通路2本を1本へ統合する意味ではない。開口の実幅と各車線の取付けはCADで別途確定する。

パレタイズの旧東SHを**完成後の通常運用図から削除する**。赤字で示された位置に「パレタイズ出口SH」を置き、旧位置に「閉鎖」ラベルや未使用の開口を残さない。この「新」は今回の**見取り図上の位置指定**であり、本書だけで現場の建築改造内容を決定しない。

### 1.2 外通路の走行線

通常運用で描く動線は2系統を区別する。

```text
〔パレタイズへ進入〕
製品倉庫東SH → 外通路を西方向へ移動 → パレタイズ西SH（入口）

〔製品倉庫へ戻る〕
パレタイズ出口SH ↓ 外通路を直進 ↓ 製品倉庫東SH
```

- 外通路の水平動線を**製品倉庫の中央壁・防火SHへ接続しない**。壁中へ吸い込まれるような枝線・矢印を作らない。
- 製品倉庫西SHは通常ルートの接続先ではない。製品倉庫東SHが使えない場合に限る迂回運用は既存の別仕様として保持する。
- シャッター前停止点、外通路上の実旋回点、実際の車線占有制御は、本図から推測して確定しない。

### 1.3 シャッターの運用（位置と運用を別属性で管理）

| 設備                         | 通常運用         | 描画位置と補足                                                 |
| ---------------------------- | ---------------- | -------------------------------------------------------------- |
| パレタイズ西SH               | 入口             | パレタイズ南面・西側。変更しない。                             |
| パレタイズ出口SH             | 出口             | パレタイズ南面。製品倉庫東SH・東側主通路群と南北軸を合わせる。 |
| 旧パレタイズ東SHの描画       | 完成図から削除   | 旧位置の開口・「閉鎖」記号を残さない。                         |
| 製品倉庫西SH                 | 通常不使用       | 東SH故障時の迂回運用を否定・削除しない。                       |
| 製品倉庫東SH                 | 通常の進入・退出 | 出口SHの真下、東側主通路2本の真上。                            |
| 倉庫内部・北防火SH／南防火SH | 倉庫西・東の往来 | 外部の入出庫SHと別設備。中央壁の2か所だけを通る。              |

既存の「迂回ルート切替時はパレタイズ入口・出口を反転する」という運用条件は残し、今回の通常運用図の描き替えで消さない。シートSH／重量SH／防火SHの開状態・PLC許可信号も既存仕様どおり別管理する。

## 2. パレタイズエリア内部

- PGW1～8、PM1～5、HI・包装機・HOの設備の相対順序は既存資料を維持。上部は設備列であり入口ではない。
- 走行通路1、走行通路2は**それぞれ双方向・1車線**。両端で相互接続する。2本を通路群として見た場合に双方向2車線扱いとするが、**通路1・2をそれぞれ一方通行にしない**。
- 走行方向の表示は各通路に「← →」の両方向を明示する。片向きの長い青矢印だけで一方通行の印象を与えない。
- PGW、PM、包装機、OT1～3は通路1から接続する。具体的な接続点・荷役停止点は実CAD確認事項。
- **OT1・OT2・OT3は建屋内の南側壁際**。パレタイズ出口SHの東（右）隣に、西から東の順で並べる。走行通路2の途中や外通路、製品倉庫側に浮かせて描かない。
- パレタイズエリア内の専用AGF待機位置WPは廃止済み。出口横へ勝手に復活させない。

## 3. 製品倉庫の配置・通路

### 3.1 保管ブロックと主通路の左右順

**西から東への平面上の順序は以下のとおり。**

```text
西端                                                       東端
 WB1～WB3 │ 西側主通路1・2 │ 中央壁＋防火SH2か所 │ 東側主通路1・2 │ EB1・EB2
```

- 主通路は**中央壁・防火SH側**に寄せる。建屋の西端・東端に移動させない。
- 西側2本＋東側2本＝計4本。**4本の道路**と**1本の道路の車線数**を混同しない。
- 主通路の個別方向・車線・すれ違いなど、利用者がまだ指定していない物理属性は未確定のままにする。
- 各保管ブロック内の行レーンは主通路とは別に、各行が双方向1車線。**同行内のAGF2台横並び通行禁止**。対向待機・譲り合い方法は別途設計する。
- 中央壁の任意横断不可。倉庫の東西横断は北・南の防火SH2か所のみ。既存資料にある各防火SHの上下レーンの一方通行指定を維持する。

### 3.2 倉庫容量と表示形状は固定

| ブロック | 構造                          |      容量 |
| -------- | ----------------------------- | --------: |
| WB1      | 7行×13列×2段                  |     182PL |
| WB2      | 3行×13列×2段                  |      78PL |
| WB3      | 13行×13列×2段                 |     338PL |
| EB1      | 3行×（9列＋空列1列＋8列）×2段 |     102PL |
| EB2      | 3行×（9列＋空列1列＋8列）×2段 |     102PL |
| **合計** | 西598PL＋東204PL              | **802PL** |

- **EB1・EB2を文字の配置都合で短くしない**。表示ラベルはラック図形の外側へ配置し、寸法・セル数を維持する。
- 東側の第10列はパレットなし。AGF走行可能かどうかは未確定であり、自動で通路化しない。

## 4. EB2南側・設備エリアの位置と向き

**「EB2の南側に位置する」ことと「東側主通路からアクセスする」ことを同時に満たす。** EB2の東隣・建屋右端の単なる付属欄へ移動させない。設備全体を横一列に並べるのも誤り。

### 4.1 正しい相対配置（文字図）

```text
                            北：EB2側
                  EB2（製品パレット置き場）
                            │
               東側主通路からのアクセス
                            │
   ┌──────────────────┬─────────────────────────────┐
   │ 通路側／左列     │ 空パレット整列機① ② ③ ④ ⑤ │ ← 上段・横方向
   │                  ├─────────────────────────────┤
   │ AGF待機位置① ─  │                             │
   │ AGF待機位置② ─  │                             │
   │ AGF充電位置① ─  │ 空パレ置き場                 │ ← 整列機の下段
   │ AGF充電位置② ─  │ 【AGF進入禁止】              │
   └──────────────────┴─────────────────────────────┘
                            南
```

- **通路側の左列に、待機2か所→充電2か所を上から下へ縦一列**に配置。各AGFは**横向きの車体姿勢**（長手方向を東西方向）で描く。「横向き」は4台分の駐車位置を東西横並びにする意味ではない。
- 空パレット整列機5台は右側・上段の横並び。**整列機を待機／充電4か所と同じ一列へ並べない**。
- 空パレ置き場は右側・整列機の下段。AGF進入不可、荷受け・退避・近道として走行ノード／エッジを作らない。
- 待機枠2・充電時停車枠2・充電器本体2台は別概念として管理する。各充電器のID対応と実停止位置は未確定。
- このエリアへのアクセス元は**既存の東側主通路2本の通路群**。設備の存在を理由に東側第3主通路を増設しない。どちらの主通路から分岐するかは未確定。

### 4.2 EB2南側以外の待機候補は削除しない

旧ロケ前提にある`WS1～4`は候補4台分：**充電器隣2台分＋中央防火SH付近の柱前（西1・東1）**。このうちEB2南側の2台分を表す図と、倉庫全体の待機候補4台分を混同しない。柱前の2候補を別の仕様変更なしに消さない。候補番号対応と停止寸法は協議中。`CS1～2`は充電場所。`HP`は待機・充電の総称であり、単一座標でも兼用2枠でもない。
